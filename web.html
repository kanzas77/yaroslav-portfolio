📋 MAX Planner — Персональный планировщик задач

Персональный планировщик, который работает полностью в вашем браузере. Никаких серверов, регистраций и ежемесячных подписок. Ваши данные остаются только на вашем устройстве.

Что вы получите:
  • Создание задач с приоритетами и категориями
  • Цветные заметки с удобным редактированием
  • Статистика и прогресс выполнения
  • Резервное копирование в один клик
  • Работа без интернета (офлайн-режим)
  • Лицензионная система защиты
🎁 Попробовать бесплатно (7 дней) — используйте тестовый ключ:
MAX-MW3Z-JJX2-MZN-XF8
💾 Где хранятся ваши данные:
Вся информация сохраняется локально в браузере в технологии localStorage под следующими ключами:
• max_tasks — ваши задачи
• max_notes — ваши заметки
• max_license_expiry — срок действия лицензии

📍 Физическое расположение файлов на компьютере:
• Chrome: C:\Users\[Имя]\AppData\Local\Google\Chrome\User Data\Default\Local Storage\leveldb\
• Firefox: C:\Users\[Имя]\AppData\Roaming\Mozilla\Firefox\Profiles\[профиль]\storage\default\
• Edge: C:\Users\[Имя]\AppData\Local\Microsoft\Edge\User Data\Default\Local Storage\leveldb\
• Яндекс Браузер: C:\Users\[Имя]\AppData\Local\Yandex\YandexBrowser\User Data\Default\Local Storage\leveldb\
⚠️ Важно: Файлы localStorage имеют бинарный формат (LevelDB) и не предназначены для ручного редактирования. Для переноса данных между устройствами используйте встроенную функцию экспорта/импорта (кнопка 💾 в правом верхнем углу приложения).
